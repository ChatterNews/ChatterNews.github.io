# Group stories and USB collection

Orbit links a group with a story code. The code works without a server: it labels
work for the same story. It does not transfer files, fetch the brief, grant access,
or synchronize computers. A USB drive carries the saved work.

## Start together

1. The lead or adviser opens the story plan in Slate and selects **Work with a group**.
2. Put the displayed code on the board. Students choose **Join a story** in Slate.
   They may enter a friendly story name; joining alone cannot retrieve the brief.
3. Each student chooses **Make my piece**, names it, and chooses writing, video,
   audio or a graphic. Existing work can be added as a copy without replacing it.
4. **Add source media** attaches external pictures, audio and video. Record the
   creator, license and source. Unused attached sources are included in the save.
   Existing permission checks still apply; importing is not publication approval.

A mistaken valid code can be corrected under **Joined the wrong story?**. Orbit
keeps the original work and connects a copy to the correct story.

## Save and collect

- **Save my piece** includes the editable project, its source bytes, outputs and
  saved versions. Browser autosave alone is only a copy on that computer.
- **Save group collection** captures local work belonging to that code and packs
  the collected versions. It preserves the source contributions separately.
- Supported browsers can choose a USB folder. Each save creates a uniquely named
  folder, checks the written bytes and writes its completion receipt last.
- Other browsers download a uniquely named `.chatter` file. Move it to the USB
  drive and check it there. Download initiation is not proof of a completed copy.
- Collect several files or a selected folder through the story's group controls.
  A file for another code is rejected there; open it with **Open a Story Drive**
  to keep that story separate. One drive can hold many stories with the same title.
- Recollecting the same saved versions is harmless. The collector is a duty of
  a lead or adviser, not a new badge role. No automatic winner replaces the main.

Group archives currently allow 256 revisions, 512 MiB packed/expanded data and
256 MiB per ZIP entry. A full snapshot counts as an entry. Split oversized work
into smaller contributions. Older ordinary Story Drives retain their existing
2 GB allowance. Originals and previous save attempts remain intact on failure.

## Assemble the story

**Compare writing** opens collected versions beside the main draft. All pieces
start open; the collapsed chooser can filter them or reveal earlier versions.
Read, highlight and insert passages, or add whole writing. Undo works in Desk.
The main writer must own the local draft or be an adviser. Use **I will lead** in
Slate for an unowned inbox.

**Use writing as main** asks you to review the choice and keeps the previous main
writing first. Writing transfer preserves supported text formatting; pictures
are brought through the media controls rather than copied as foreign URLs.

**Open editable copy** continues a received video, audio, graphic or article as a
separate local project. **Bring media here** imports the source files and rendered
image/audio/video outputs through the normal checks, retains credit information,
and makes them available to the destination tools. Approved attached pictures
appear in Desk's Picture Box; attached audio appears in Chatterbox. Large pictures
use a smaller display copy in the writing while the full original stays attached.

Two edits from the same base remain visible as alternative versions. Device
clocks do not choose a winner. Same-name students and projects retain distinct
identities. Imported contributor names do not become adviser badges.

## Compatibility and classroom check

Database 13 adds group revision storage without deleting earlier records. Portable
format 8 carries group history and explicit attachments; formats 1–7 still open.
Whole-story saves and Finish session carry history. The adviser records backup
includes revision metadata and blob hashes, not a substitute for portable media.
Frozen September native kits do not acquire the website update automatically.

Automated tests and isolated Chromium checks cover the software paths. Before a
classroom rollout, rehearse one actual drive on a managed Chromebook and staff
Windows/Mac: save two same-title stories, collect four contributions, open media,
assemble writing, save, eject and reopen. Physical USB, school permissions and
Safari differences are not certified by the automated checks.
