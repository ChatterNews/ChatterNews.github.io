# Studio drum-kit samples

The WAV files in this directory come from `Boochi44/free-drum-samples`, commit
`77ba31428a079dd8f17c8e144c1e649ea0a198b3`.

Source: https://github.com/Boochi44/free-drum-samples

The source project releases the samples under the Creative Commons Zero 1.0
Universal public-domain dedication (CC0 1.0). The source notes that several
sounds were derived from Edward Loveall's CC0 TR-808 recordings; the remaining
808 tones were synthesized and the vintage kit was produced by processing
those sounds.

License: https://creativecommons.org/publicdomain/zero/1.0/
