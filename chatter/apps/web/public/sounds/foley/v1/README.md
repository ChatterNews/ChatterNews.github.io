# Foley included sound library v1

Curated September 21, 2026. 38 files, 22,964,370 bytes of audio (21.9 MiB).

Each selected source is published under CC0 1.0 Universal:
https://creativecommons.org/publicdomain/zero/1.0/
Attribution is retained for educational provenance even where not required.
This is a curated starter library, not an industry certification.

Kenney packs: https://kenney.nl/assets/impact-sounds,
https://kenney.nl/assets/interface-sounds, https://kenney.nl/assets/music-jingles.
Original pack license texts accompany this manifest.

BigSoundBank: https://bigsoundbank.com/licenses.html. Individual sound pages
also identify CC0; credits use the individual contributor, not only the site owner.

artisticdude: https://opengameart.org/content/swishes-sound-pack (CC0).

Original WAVs are unchanged. Selected Kenney OGG files were decoded into 16-bit
PCM WAV at their source sample rate/channel count for browser compatibility;
this conversion does not improve fidelity. No normalizing or resampling applied.
Duration, waveform, format, source filename, conversion notes and exact SHA-256
hashes are in catalog.json. The application saves that attribution with each use.

Sonniss is linked as an external download/import option only. Its sounds are not
in this bundle: https://sonniss.com/gdc-bundle-license/.
