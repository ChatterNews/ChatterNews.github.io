Your work.
Your device.

Orbit is a static website with a local workspace. It has no student account server, cloud storage, analytics service, or automatic publishing connection.

What stays local

Story text, recordings, images, projects, badges and crew notes are stored in the browser on this device. Transcription and image checks run here too. Saving creates files in a folder you choose or starts a browser download. The website edition does not open a sharing service.

What uses the internet

Orbit opens directly. It downloads room tools as you use them and downloads a processing model when its feature needs it. Optional offline preparation stores the full toolkit. The browser also checks for app updates. GitHub receives ordinary connection information, including IP addresses and requested public file paths. Orbit reuses cached tools. A missing tool can only be fetched from its exact, listed public file on this site; it must pass a size and checksum check. Other URLs, query strings, writes, caller headers and external services are blocked by the app gateway. Story navigation uses URL fragments, which are not sent in HTTP requests.

What the school controls

Browser extensions, device monitoring, Enhanced Spell Check, dictated keyboard input, cloud-synced download folders, backups and operating-system services are outside Orbit's control. Ask IT to review those settings. Use local spell checking and local or USB save destinations when content must stay on device. Do not treat this page as a promise about those separate systems.

Before students arrive

  1. Allow this site, service workers, local browser storage, WebAssembly and the microphone/camera features your lessons use.
  2. On an actual managed student profile, open Orbit while online. The desk opens without a full-toolkit download. Allow extra storage for media; the optional complete offline toolkit is roughly 350 MB.
  3. Make a practice story, use Studio and record a short take. If offline lessons are needed, choose Files → Prepare for offline use and wait for Ready to work offline. Disconnect Wi-Fi and check the lesson.
  4. Finish session, check the exported .chatter files or session ZIP, then reopen a story file. Confirm which folder IT permits.
  5. Check what logout does to local browser storage. If it is erased, the site loads its tools again next session. Always export work before logout.

Patching

An update waits for all Orbit tabs and app windows to close. Save the session first, then reopen the homepage. Updated tools load as needed. Prepare the new release separately if you need its complete toolkit offline. Workspace recovery keeps the same local identity across app releases. Exported files remain the dependable handoff. Never clear site storage as an update step.

Device expectations

Managed Chromebooks with current Chrome are the primary school target. Mac and Windows Chrome use the same site. Recent Safari on iPhone and iPad can use local downloads; iOS/iPadOS 18.4+ is the pilot target. Studio, video encoding and recording still need a real-device check. Full offline preparation covers app tools, not the external source/license archives linked below. Download those separately while online if you need them. A ZIP session is limited to 256 MB before packing; use individual story saves or the verified folder option for larger sessions.
